# XIAO-40 工作区文件层阶段

本段接续 worker/工具快照基线 `2c942c1fc472568f878e068bdc4204a065cc67a1`，实现 P3 所需的真实持久文件边界，不改变默认 fixture 装配、数据库 V1–V5 或历史基线文件。它是后端文件层交付，尚不是公共 worker、五工具报告或 P3 验收。

## 宿主契约

`plugin.api.FilePort` 只使用 Java 类型。宿主以已准入调用的 tenant、task UUID、稳定 effect operation UUID 和取消检查绑定端口；这些值不进入模型参数。模型仍使用基线的 `file_path/content`、`file_path/offset/limit` 和 `present.files` 形状，后续装配不能把 operationId 或可选 CAS 开关暴露给模型。

`read` 默认调用参数应为 offset=1、limit=2000，返回行号文本、存在性、版本、hash、UTF-8 字节数和总行数。不存在观察与空文件不同。路径是相对逻辑文件名：拒绝绝对路径、空组件、点组件、反斜线、盘符和控制字符；嵌套逻辑路径可用，但不会拼成宿主 OS 路径。本段不新增 edit/glob/grep/shell。

每个宿主绑定固定当时的观察版本。`write` 首先持久化不可变的预期版本与输入摘要，再提交内容和操作收据；不允许未观察写入。当前版本与该预期不符时为 `FS_STALE_VERSION`，重启后也不能采用后续 read 更新过的观察来替换原条件。同一 operation 和参数返回原收据，参数或操作种类变化为 `FS_OPERATION_MISMATCH`。旧操作重放不会回滚后来写入，内容相同也递增版本，避免 ABA。两个进程从同一观察出发只有一个 CAS 成功。

`snapshot` 要求已观察/写入的当前版本，首次操作固定内容、版本、hash 和字节数；重放返回这份不可变收据。它仅为后续 present 提供输入，**不是产物登记、报告生产者或发布成功的证据**。present 仍需绑定自身 invocation、校验报告、先记上传意图，再原子提交输出验证、发布、事件与结算。默认 summary 的旧产物分支未在本段替代。

## 实际磁盘边界及故障恢复

`SecureWorkspaceStore` 要求运营者预建原生 POSIX、权限 0700 的私有根。每次操作从文件系统根沿 `SecureDirectoryStream`/NOFOLLOW 打开每一层目录；后续文件打开、临时写入和原子 rename 都相对固定目录句柄。tenant/task 的摘要定位状态与锁文件，模型路径仅作为状态中的逻辑键。根或状态/锁文件换成符号链接时拒绝；已打开根随后被替换也不能把本次写入转向替代目录。不支持安全目录流的存储失败，不能降级成先检查再按绝对路径打开。

同 JVM 分段锁与跨 JVM `FileChannel.lock` 串行化每个工作区事务。状态包含当前文件、观察及恢复收据；临时状态文件 fsync 后以同目录 rename 替换，再 fsync 实际目录句柄。异常退出留下的 `.part` 不参与读取，当前状态始终为完整旧版或新版；提交收据与对应内容在同一个状态中。状态的 scope、格式版本、摘要以及各文件/收据的内容摘要和大小在加载时检查。

这是私有宿主存储边界，不声称能防拥有同一 OS 账户或底层卷管理权限的攻击者。运营者不得修改活动根、删除锁文件或并发编辑状态。工作区当前文件合计最多 16 MiB；单文件受同一上限约束。恢复收据保留旧内容，完整持久状态另限 128 MiB、最多 100 条操作/文件收据（20 次工具调用，每次 present 至多 4 个文件加根收据）；达到上限明确失败。专用 JSON 解析器使用相同有界文档/字符串上限，不扩大共用模型/账本解析器的边界。

本段不删除活动工作区，也不凭 TTL 推断写者退出。七天保留/清理必须由后续宿主装配在可信静止事实之后执行；未安装自动清理前不能作为生产保留承诺。报告仍限 1 MiB，其六栏目、持久生成时间、有效抓取证据、引用成员和授权 Markdown 下载由接续段闭合。

## 默认验证及证据边界

默认 `./mvnw -B -ntp verify` 增加 `WorkspaceIT`，Windows 入口按现有机制经 WSL，Linux 直接运行同一个原生文件系统脚本。缺少 SecureDirectoryStream/POSIX、JDK21 或 WSL 等必需资源失败，不跳过。P2、模型、快照/生命周期以及公共适配器原有默认门禁不变。

`WorkspaceScenario` 使用实际 ext4 文件、两个独立 JVM 的 CAS 竞争，以及进程在精确窗口退出。另验证租户/任务隔离、路径/符号链接、固定根被替换、取消/正常对照、分页、空文件、UTF-8、ABA 与 16 MiB N−1/N/N+1。测试保留调用结果和进程退出/目录清理收据。这些是文件层真实 IO/退出证据，不是 worker 模型回合、公共网络或 present 产物生产证据。

首次针对性验证暴露持久状态超过共用 Jackson 默认 20,000,000 字符限制；已换为专用有界解析器，原失败日志保留。历史自然 readiness 超时和旧 CI SQL 失败原因仍未确认，不能把本段已解释的问题当成其根因。
